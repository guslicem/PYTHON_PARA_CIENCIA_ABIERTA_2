# LICENCIAS Y USO de los DATASETS

Los datasets en esta carpeta están distribuidos bajo las licencias otorgadas por sus creadores.

- [FROM_DIGITAL_CSIC](./FROM_DIGITALCSIC/): Datasets proporcionados por URICI para la generación de contenido del Curso. Solo se permite su uso en el contexto de este curso, para cualquier uso ajeno al mismo, se requiere autorización expresa de los creadores {isabel.bernal_AT_bib.csic.es}.

- [Thyroid_Diff](./Thyroid_Diff.csv): Dataset descargado desde [Kaggle](https://www.kaggle.com/datasets/jainaru/thyroid-disease-data), que se distribuye bajo [Licencia Creative Commons 4.0](https://creativecommons.org/licenses/by/4.0/)

- [titanic](./titanic/): Dataset basado en el concurso [Titanic - Machine Learning from Disaster
](https://www.kaggle.com/competitions/titanic).

- [vivienda](./vivienda.csv): Dataset [Datos precios viviendas y más España](https://www.kaggle.com/datasets/dan0li/datos-precios-viviendas-y-mas-espaa) distribuido bajo [Licencia Apache 2.0](https://www.apache.org/licenses/LICENSE-2.0).
